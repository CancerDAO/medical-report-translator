# Medical Report Translator

把复杂的医学报告翻译成你能看懂的大白话。

## What it does

当患者上传病理报告、基因检测报告或影像报告时，将专业医学术语翻译成通俗语言，解释：
- "这到底是什么意思？"
- "严重吗？"
- "下一步该怎么办？"

## Installation

```bash
npx skills add CancerDAO/medical-report-translator
```

## Usage

用户发送报告内容或图片时自动激活，支持：
- 直接粘贴报告文字
- 上传报告图片（OCR后翻译）
- 询问"帮我看看这份报告"、"看不懂"、"什么意思"

## Outputs

翻译结果包含：
1. 一句话总结
2. 逐项解释（通俗化每个关键术语）
3. 严重程度评估（低/中/高，不用医学分期）
4. 下一步建议（鼓励和医生讨论）

## Safety

所有翻译末尾附注：以上内容仅供参考，具体治疗方案请与您的主诊医生讨论。

## Example

Input: "低分化腺癌，侵及浆膜层，淋巴结转移4/12，脉管侵犯阳性"

Output:
> **一句话总结**：这是一份分期偏晚、恶性程度较高的报告，需要积极治疗。
>
> **逐项解释**：
> - **低分化腺癌** → 恶性程度偏高，生长速度较快
> - **侵及浆膜层** → 肿瘤已长到最外层，分期上升
> - **淋巴结转移4/12** → 12枚淋巴结中4枚已有转移
> - **脉管侵犯阳性** → 有向血管/淋巴管扩散的迹象
>
> **严重程度**：高
>
> **下一步**：建议和医生讨论术后辅助治疗方案和定期复查计划。
>
> ⚠️ 以上内容仅供参考，具体治疗方案请与您的主诊医生讨论。
