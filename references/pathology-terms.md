# 病理术语参考

## 分化程度

| 术语 | 通俗解释 | 备注 |
|---|---|---|
| 高分化 | 恶性程度低，接近正常细胞，生长慢 | 预后相对较好 |
| 中分化 | 恶性程度中等 | 预后居中 |
| 低分化 | 恶性程度高，细胞形态与正常差异大 | 生长较快 |
| 未分化/间变 | 恶性程度非常高，几乎无法辨认来源 | 预后差 |

## 侵袭相关

| 术语 | 通俗解释 | 临床意义 |
|---|---|---|
| 侵及浆膜/脏层胸膜 | 肿瘤已长到器官最外层 | T4分期，分期上升 |
| 侵及外膜/穿透 | 肿瘤穿透整个器官壁 | 复发风险高 |
| 脉管癌栓阳性 | 肿瘤已进入血管或淋巴管 | 远处转移风险高 |
| 脉管癌栓阴性 | 未发现进入血管/淋巴管 | 相对好 |
| 神经侵犯阳性 | 肿瘤侵入神经纤维 | 疼痛风险高，可能需要局部放疗 |
| 神经侵犯阴性 | 未发现侵入神经 | |
| 切缘阳性 | 手术切除边缘有残留肿瘤细胞 | 术后辅助治疗可能必要 |
| 切缘阴性 | 切除干净，边缘未见残留 | |

## 淋巴结

| 术语 | 通俗解释 |
|---|---|
| 淋巴结转移X/Y | Y枚淋巴结中X枚已有转移 |
| 区域淋巴结肿大 | 该区域淋巴结已有癌细胞侵犯 |
| 远处淋巴结转移 | 非区域淋巴结受侵犯，分期更晚 |

## 增殖指标

| 术语 | 通俗解释 |
|---|---|
| Ki-67 <15% | 生长速度慢 |
| Ki-67 15-30% | 生长速度中等 |
| Ki-67 >30% | 生长速度快 |
| Ki-67 >70% | 生长速度非常快，侵袭性强 |

## 其他

| 术语 | 通俗解释 |
|---|---|
| 粘液腺癌 | 分泌粘液的腺癌，有时预后较好（看具体亚型）|
| 印戒细胞癌 | 预后较差的特殊类型腺癌 |
| 肉瘤样癌 | 兼有癌和肉瘤特征，恶性度高 |
| 坏死 | 肿瘤中心缺血坏死，生长快 |
| 钙化 | 常是陈旧性病变或良性疾病标志 |
