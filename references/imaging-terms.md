# 影像报告术语参考

## 肿瘤描述

| 术语 | 通俗解释 | 临床意义 |
|---|---|---|
| 肿块/占位 | 影像上看到的异常团块 | 需要结合大小、形态、强化判断良恶性 |
| 结节 | 小的圆形/类圆形占位 | 小结节多为良性，定期复查；大的需警惕 |
| cm大小 | 肿瘤直径 | 越大分期可能越晚（但要结合其他因素）|
| 分叶征 | 肿瘤边缘像花瓣一样 | 恶性肿瘤特征之一 |
| 毛刺征 | 肿瘤边缘有细短毛刺 | 恶性肿瘤特征之一 |
| 空洞 | 肿瘤中心空洞 | 可能是恶性空洞（壁厚、不规则）或良性 |
| 钙化 | 肿瘤内有钙质沉积 | 需看形态：爆米花钙化多是良性，泥沙样需警惕 |

## 转移相关

| 术语 | 通俗解释 | 临床意义 |
|---|---|---|
| 多发结节/播散 | 多个部位出现结节 | 可能是转移，需全身检查 |
| 淋巴结肿大 | 淋巴结增大 | 可能是转移，也可能是炎症反应 |
| 纵隔淋巴结肿大 | 纵隔区域淋巴结增大 | 区域转移，分期上升 |
| 远处淋巴结肿大 | 非区域淋巴结增大 | 远处转移，分期更晚 |
| 胸腔积液 | 胸腔内有液体 | 需穿刺确认：漏出液/渗出液/恶性胸水 |
| 心包积液 | 心包内有液体 | 需穿刺确认性质 |
| 肝转移 | 肝脏出现转移灶 | 晚期，治疗目标延长生存 |
| 骨转移 | 骨骼出现转移灶 | 晚期，可能需要护骨治疗 |
| 脑转移 | 脑部出现转移灶 | 晚期，需全脑放疗或手术 |

## 侵袭相关

| 术语 | 通俗解释 | 临床意义 |
|---|---|---|
| 胸膜侵犯 | 肿瘤累及胸膜 | 可能有胸水，分期上升 |
| 胸壁侵犯 | 肿瘤侵犯胸壁 | 局部晚期，可能需要放疗 |
| 血管侵犯 | 肿瘤包绕或侵犯血管 | 手术难度增加，可能无法完整切除 |
| 气管/支气管侵犯 | 肿瘤累及气道 | 可能需要气道支架或消融治疗 |

## 治疗相关

| 术语 | 通俗解释 | 临床意义 |
|---|---|---|
| 新发病灶 | 治疗后新出现的病灶 | 可能复发或转移 |
| 病灶增大/进展 | 原有病灶变大 | 需要调整治疗方案 |
| 病灶缩小/缓解 | 原有病灶变小 | 治疗有效，继续当前方案 |
| 病灶稳定 | 病灶没有明显变化 | 当前方案控制住了疾病 |
| 空腔/空洞形成 | 治疗后肿瘤坏死形成的空洞 | 可能是治疗有效（尤其免疫治疗后）|

## 常见部位描述

| 部位 | 术语 | 通俗解释 |
|---|---|---|
| 肺 | 磨玻璃密度 | 可能是早期癌或炎症，需随访 |
| 肺 | 实性密度 | 恶性可能性较大 |
| 肝 | 低密度/高密度 | 需结合增强判断：囊肿低密度，血管瘤高强化，肝癌快进快出 |
| 骨 | 成骨性转移 | 骨头里有新骨形成，常见于前列腺癌、乳腺癌 |
| 骨 | 溶骨性转移 | 骨头被破坏，常见于肺癌、肾癌 |
| 脑 | 长T1长T2信号 | 影像术语，需结合强化判断 |
| 脑 | 环形强化 | 可能是转移瘤或脓肿 |
